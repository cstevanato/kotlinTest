# Projeto: Aplicativo de Lista de Tarefas

## Descrição
Desenvolver um aplicativo Android simples para gerenciar uma lista de tarefas. Os usuários poderão adicionar, editar e excluir tarefas. As tarefas serão exibidas em uma lista, e cada tarefa terá um título e uma descrição.

## Funcionalidades
- Adicionar nova tarefa com título e descrição.
- Editar tarefa existente.
- Excluir tarefa.
- Marcar tarefa como concluída.
- Interface de usuário responsiva.

## Requisitos Técnicos
- Linguagem: Kotlin
- Arquitetura: MVVM
- Banco de dados local: Room
- Biblioteca de UI: Jetpack Compose
- Gerenciamento de dependências: Gradle
