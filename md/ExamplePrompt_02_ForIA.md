# Projeto: Aplicativo de Conversor de Moedas

## Descrição
Desenvolver um aplicativo Android que converte valores de uma moeda para outra usando taxas de câmbio em tempo real.

## Funcionalidades
- Selecionar moeda de origem e destino.
- Inserir valor a ser convertido.
- Exibir resultado da conversão.
- Atualizar taxas de câmbio automaticamente.

## Requisitos Técnicos
- Linguagem: Kotlin
- API para taxas de câmbio: [Open Exchange Rates](https://openexchangerates.org/)
- Biblioteca de rede: Retrofit
- Biblioteca de UI: Material Design
- Persistência de dados: SharedPreferences para salvar configurações do usuário
