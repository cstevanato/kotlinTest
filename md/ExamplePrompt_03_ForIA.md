# Projeto: Aplicativo de Notícias

## Descrição
Desenvolver um aplicativo Android que fornece as últimas notícias de várias categorias (tecnologia, esportes, entretenimento, etc.) usando uma API de notícias.

## Funcionalidades
- Exibir lista de notícias por categoria.
- Visualizar detalhes da notícia.
- Favoritar notícias para leitura posterior.
- Pesquisar notícias por palavra-chave.

## Requisitos Técnicos
- Linguagem: Kotlin
- API de notícias: [News API](https://newsapi.org/)
- Biblioteca de rede: Volley ou Retrofit
- Banco de dados local: Room para favoritos
- Navegação: Navigation Component
- Design responsivo: ConstraintLayout
